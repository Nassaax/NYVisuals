# Clients

Un dossier par client, créé automatiquement quand Nasser écrit « Nouveau client : [nom] ».

- `fiche.md` : réponses au questionnaire, choix (logo, couleurs, formule), retouches demandées.
- `todo.md` : la liste de choses à faire, cochée au fur et à mesure.

Le site de chaque client vit dans son propre dépôt GitHub privé.
